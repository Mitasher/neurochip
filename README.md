# SEU-устойчивость: фон-Нейман vs нейроморф (AltAI)

Экспериментальное сравнение устойчивости к **SEU (Single Event Upset)** — однобитовому
радиационному сбою — двух архитектур:

* **фон-Нейман** — обычный микроконтроллер (широкие слова float32 / int8, регистры,
  счётчик команд) — numpy-модель;
* **нейроморф** — чип AltAI (тернарные веса `{-1,0,1}`, спайковая бинаризация),
  проверка идёт **прямо на эмуляторе чипа** (golden model Kaspersky Neuromorphic
  Platform).

Вход общий для обеих платформ: тернарная матрица `W` и бинарный вектор `x`.
Вывод разделён на **два эксперимента**:

* **Эксперимент 1 — линейная алгебра:** `y = W · x`. Метрика — отклонение выхода.
* **Эксперимент 2 — перцептрон:** `class = argmax(W·x)` / `step(W·x − θ)`. Метрика —
  смена решения классификатора.

## Структура

```
config.py              параметры SEU: N_TRIALS, N_CHIP_SYNAPSE, размеры, цели битфлипа, seed
algorithms.py          эталонные алгоритмы: linear_transform(), threshold_classifier()
fault_injection.py     инъекторы битфлипа (IEEE-754 / int / тернар / мембрана)
platforms/
  vonneumann.py        numpy-модель МК (float32 / int8, аккумулятор, счётчик цикла)
  neuromorph.py        numpy-модель LIF (мембрана) + сверка с чипом
  altai_chip.py        запуск инъекции в синапс ПРЯМО НА ЧИПЕ AltAI (через воркер)
  altai_worker.py      воркер: сборка конфига + прогон на чипе в отдельном процессе
metrics.py             отклонение, SDC, смена решения, fatal/crash, самовосстановление
seu_experiment.py      главный прогон → results/seu_report.json (разделён на 2 эксперимента)
report.py              текстовые таблицы + графики по двум экспериментам
docs/
  01_theory_seu.md     теория SEU (механизм, типы, сечение сбоя)
  02_architectures.md  разбор архитектур и обоснование гипотезы
  03_experiment.md     методика, результаты, вывод (что вход / что выход / где считалось)
results/               seu_report.json + графики
changes.md             что изменено в проекте и зачем
```

## Запуск

```bash
source venv/bin/activate

# инъекция в синапс — на эмуляторе чипа AltAI (по умолчанию); остальное на numpy
python seu_experiment.py

# всё на numpy-моделях (быстро, без чипа)
python seu_experiment.py --no-chip

# + сверка numpy-модели нейроморфа с чипом на чистых входах
python seu_experiment.py --altai-validate

# таблицы и графики
python report.py
```

> Каждая инъекция в синапс на чипе пересобирает placed-конфиг (~18–24 с) в отдельном
> процессе, поэтому на чипе прогоняется `N_CHIP_SYNAPSE=18` инъекций (на numpy-моделях
> `N_TRIALS=100`). Это полноценная проверка на чипе, а не имитация.

## Ключевые результаты (seed=42)

Вход: `W·x = [1, -1, 2, 3]` → класс `3`, спайкуют нейроны `{0, 2, 3}`.

**Эксперимент 1 — линейная алгебра** (отклонение выхода `‖Δ‖/‖ref‖`):

| Платформа | где | макс. откл. | `inf`-выходов |
|---|---|---:|---:|
| фон-Нейман float32 | numpy | 130× | 10.7% |
| фон-Нейман int8 | numpy | 68000× | 19.0% |
| **нейроморф AltAI** | **ЧИП** | **0.58×** | **0.0%** |

**Эксперимент 2 — перцептрон** (смена решения, знаковая форма на обеих платформах):

| Платформа | где | смена решения | fatal | crash |
|---|---|---:|---:|---:|
| фон-Нейман float32 | numpy | 11.3% | 3.3% | 7.3% |
| фон-Нейман int8 | numpy | 31.0% | 13.7% | 5.3% |
| **нейроморф AltAI** | **ЧИП** | 11.1% | **0.0%** | **0.0%** |

**Главный вывод (честно):** по частоте смены знакового решения чип сопоставим с
float32-МК — одиночный слой сам по себе не «неуязвим». Решающее отличие в **характере
отказа**: на чипе сбой **ограничен по величине (`≤0.58×`), тих (SDC) и невзрывной**
(`fatal=0%`, `crash=0%`, ни одного `inf`), тогда как у МК сбой часто **катастрофичен**
(до 68000× по норме, до 13.7% `inf`, 5–7% крахов потока управления). Дополнительно
(на numpy-модели мембраны): транзиент самоустраняется за ~5 тиков (85% случаев).

Подробности и трассы «вход → изменение → результат» — в
[docs/03_experiment.md](docs/03_experiment.md) и `results/seu_report.json`.
