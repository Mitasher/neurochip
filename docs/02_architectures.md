# Архитектуры: фон-Нейман против нейроморфа (AltAI)

Цель документа — разобрать обе архитектуры на уровне хранения и обработки данных и
обосновать, **почему один-единственный битфлип (SEU, Single Event Upset) критичен
для классического фон-Неймановского микроконтроллера (МК), но почти безвреден для
нейроморфного чипа AltAI**. Где приводятся количественные оценки, они формулируются
как ожидание/гипотеза, проверяемая в эксперименте (см. `docs/03_experiment.md`).

---

## 1. Фон-Неймановская архитектура (обычный микроконтроллер)

### 1.1. Принцип

Классический микроконтроллер построен по фон-Неймановской схеме:

- **Общая память** для команд и данных — одно адресное пространство, в котором
  лежат и инструкции программы, и обрабатываемые данные/веса.
- **Единый счётчик команд** (PC, Program Counter) — указывает на адрес следующей
  инструкции; вся логика исполнения последовательна и централизована.
- **Регистровый файл** — небольшой набор быстрых регистров (аккумулятор, рабочие
  регистры, указатель стека SP) хранит «горячее» состояние вычисления.
- **АЛУ** (арифметико-логическое устройство) — выполняет операции над содержимым
  регистров.
- **Единая шина** между процессором и памятью — это и есть фон-Неймановское
  «бутылочное горлышко» (von Neumann bottleneck): команды и данные ходят по одному
  каналу, и пропускная способность шины ограничивает производительность.

Поток управления **жёстко централизован**: есть ровно одна «нить исполнения»,
адрес которой держит PC.

### 1.2. Как хранятся данные: широкие слова

Веса нейросети и промежуточное состояние на МК — это **широкие машинные слова**:

- `float32` — IEEE-754 одинарной точности, 32 бита;
- целые `int8` / `int32`.

#### Формат IEEE-754 (float32)

32 бита делятся на три поля:

```
| S |   E (exponent)   |        M (mantissa)         |
| 1 |     8 бит        |          23 бита            |
бит 31                                            бит 0
```

- **S** — 1 бит знака (0 — плюс, 1 — минус).
- **E** — 8 бит экспоненты, хранится со смещением (bias = 127).
- **M** — 23 бита мантиссы (дробная часть, при нормализованном числе старшая
  единица подразумевается неявно).

Значение нормализованного числа:

```
value = (-1)^S * 1.M * 2^(E - 127)
```

**Почему биты экспоненты «весят» экспоненциально.** Экспонента стоит в показателе
степени двойки. Поэтому переворот бита экспоненты домножает или делит число на
степень двойки, а не на маленькую добавку:

- переворот **младшего** бита экспоненты — множитель `2^1` (число меняется вдвое);
- переворот **старшего** бита экспоненты (вес `2^7 = 128` в поле E) — изменение
  показателя сразу на 128, то есть умножение/деление числа примерно на `2^128`
  (или на `2^64`, если флип идёт «в обратную сторону» от середины диапазона) —
  фактически скачок на **десятки порядков**: нормальное число превращается в
  `inf`, в денормал или в гигантскую величину `~2^64`;
- переворот **бита знака** S — меняет направление вклада веса на противоположное
  (`+w` → `-w`): результат может сменить знак, нейрон «передумает»;
- переворот **бита мантиссы** — относительно малый эффект: старший бит мантиссы
  даёт изменение порядка `2^-1` от величины числа, младшие биты — пренебрежимо
  малое возмущение.

Вывод по формату: распределение «опасности» по битам у float крайне неравномерно.
Около **9 из 32 битов** (знак + экспонента) при перевороте дают катастрофическое
искажение значения, а на 1000 умножений-накоплений `y = sum(W·x)` одно такое
значение `~2^64` или `inf` отравляет весь результат слоя.

#### Целые форматы

Для `int8`/`int32` переворот старшего значащего бита — это добавка `2^(n-1)`
(например, `2^31` для int32 или смена знака в дополнительном коде). Эффект тоже
велик по амплитуде, хотя и ограничен разрядностью слова, в отличие от
неограниченного `inf` у float.

### 1.3. Уязвимые мишени для SEU

SEU — это переворот одного бита в ячейке памяти/триггере под действием частицы.
На МК уязвимы:

1. **Ячейка веса в RAM** — даёт искажённое значение веса (см. амплитуды выше).
2. **Регистр-аккумулятор / рабочие регистры** — портит текущее промежуточное
   вычисление.
3. **Указатель стека (SP)** — искажает адрес возврата/локальных переменных.
4. **Счётчик команд (PC)** — искажает адрес следующей инструкции.

**Отдельный класс — отказы потока управления.** Битфлип в PC или SP уводит
исполнение в **произвольный адрес**: процессор начинает исполнять «мусор»,
данные как код, попадает в недопустимую инструкцию → **зависание, перезагрузка
(watchdog reset) или исполнение случайного кода**. Это фатальный отказ всей
программы, а **не** просто ошибка в одном числе. Важно: у нейроморфа такого
класса отказов **нет вообще** — нет единого PC/стека, которые можно «сбить».

### 1.4. Вывод по фон-Нейману

- Состояние **накапливается и долго живёт** в статических регистрах/RAM: сбитый
  бит остаётся сбитым, пока ячейку не перезапишут.
- Один сбитый бит **экспоненты или знака** рушит результат вычисления на порядки.
- Сбой в **управлении** (PC/SP) роняет всю программу целиком.

## 2. Нейроморфная архитектура на примере AltAI

### 2.1. Принцип

Нейроморфный чип (AltAI / Kaspersky Neuromorphic Platform) устроен принципиально
иначе:

- **Вычисления «в памяти»** (in-memory / near-memory): нет разделения
  память↔АЛУ, синаптические веса хранятся прямо в вычислительных элементах. Нет
  фон-Неймановского «бутылочного горлышка» — нет общей шины, по которой гоняются
  все данные.
- **Нет единого счётчика команд.** Нет одной централизованной нити исполнения.
- **Массив ядер**, каждое из которых содержит **нейроны и синапсы**. Ядра
  обмениваются короткими сообщениями — **спайками** (событийная, *event-driven*
  модель): нейрон что-то «делает», только когда приходит спайк, а не по тактам
  единого PC.

### 2.2. Тернарные веса (синапсы) `{-1, 0, 1}`

Синаптические веса в AltAI **тернарные**: каждое значение принадлежит множеству
`{-1, 0, 1}` и кодируется примерно **2 битами** (вместо 32 бит float).

**Ключевое свойство — ограниченная амплитуда искажения.** При перевороте бита
тернарного веса значение остаётся внутри маленького дискретного множества
`{-1, 0, 1}` (или клиппируется к нему). Максимально возможное изменение одного
веса — это переход вида `1 → -1`, то есть **ограниченная величина порядка
единицы**. Сравните с float, где один бит экспоненты даёт скачок на `~2^64` или
вовсе `inf`. Здесь же:

```
|Δw| <= 2     (тернар: -1, 0, 1)
|Δw| ~ 2^64   (float32: переворот старшего бита экспоненты)
```

Разница в амплитуде искажения — **десятки порядков**.

### 2.3. Спайковая бинаризация

Выход нейрона — **бинарный**: спайк / не-спайк. Формально это пороговая функция
Хевисайда:

```
spike = H(V - V_thr) = 1, если V >= V_thr; иначе 0
```

где `V` — мембранный потенциал, `V_thr` — порог. Бинаризация **обрезает
аналоговую ошибку**: если накопленное возмущение мембраны (например, из-за
сбитого синапса) **не дотянуло до порога**, оно **вообще не влияет на выход**
нейрона. Малое подпороговое возмущение поглощается порогом, а не распространяется
дальше, как это происходит в float-сумме `y = W·x`, где любое искажение слагаемого
переносится в результат напрямую.

### 2.4. Мембранный потенциал и утечка (leak)

Нейрон AltAI — это **leaky integrate-and-fire** (LIF): мембранный потенциал
интегрирует входящие спайки, но при этом **«течёт» к нулю** со временем:

```
V(t+1) = leak * V(t) + sum(входящие веса спайков)     (0 < leak < 1)
```

Из-за утечки **транзиентный сбой** в мембранном потенциале (однократный SEU в
ячейке состояния нейрона) **сам затухает за несколько тиков** — потенциал
экспоненциально возвращается к равновесию. Это **встроенное самовосстановление**,
которого нет у статического регистра МК: там сбитый бит держится, пока его не
перезапишут.

### 2.5. Распределённость

Результат на нейроморфе **не живёт в одном слове**. Информация «размазана» по
**тысячам синапсов и нейронов**: каждый отдельный синапс вносит лишь малый вклад в
суммарный потенциал. Поэтому один сбитый синапс даёт только **локальное малое
возмущение**, тонущее в массе корректных вкладов, — нет единственной «точки
отказа», как сбитая float-ячейка веса или регистр-аккумулятор на МК.

### 2.6. Нет общего потока управления

Раз нет единого PC и стека вызовов — **нечего «уронить»**. Управление
распределено и событийно: спайки маршрутизируются между ядрами, нет адреса
«следующей инструкции», который можно увести в произвольную точку. **Целый класс
управляющих отказов (зависание/перезагрузка/исполнение мусора) на нейроморфе
отсутствует.**

### 2.7. AltAI как реализация

- **Сетка ядер** с нейронами и синапсами; обмен спайками.
- **Golden model** — программный эмулятор чипа (битточная эталонная модель),
  на котором и удобно инжектировать SEU и сравнивать выход с эталоном.
- **Тернарные слои** (`TernaryDense`) с весами `{-1, 0, 1}`.
- **Активация Heaviside** (пороговый спайк).
- Платформа — **Kaspersky Neuromorphic Platform (KNP)**.

## 3. Сравнительная таблица

| Критерий | Фон-Нейман (МК) | Нейроморф (AltAI) |
|---|---|---|
| Где живут данные | Общая RAM + регистры (централизованно) | «В памяти», в синапсах/нейронах массива ядер (распределённо) |
| Разрядность/формат весов | Широкие слова: `float32` (IEEE-754, 32 бита), `int8`/`int32` | Тернар `{-1, 0, 1}`, ~2 бита |
| Эффект одного битфлипа | До `~2^64` / `inf` (бит экспоненты), смена знака; огромная амплитуда | Ограничен: `|Δw| <= 2`, часто поглощается порогом |
| Время жизни ошибки | Накапливается, держится до перезаписи (статический регистр) | Утечка мембраны гасит транзиент за несколько тиков (самовосстановление) |
| Поток управления и его уязвимость | Единый PC/SP → битфлип уводит в произвольный адрес → зависание/reset/мусор | Нет единого PC/стека → класс управляющих отказов отсутствует |
| Ожидаемая доля фатальных сбоев | Высокая (гипотеза, проверяется экспериментом) | Низкая (гипотеза, проверяется экспериментом) |

> Числа в строке «доля фатальных сбоев» здесь не приводятся как факт —
> это ожидание, которое проверяется измерениями в `docs/03_experiment.md`.

## 4. Итоговый вывод: почему SEU критичен для фон-Неймана и некритичен для AltAI

1. **Разрядность хранения определяет амплитуду искажения.** Широкое float-слово
   с экспонентой даёт при перевороте старшего бита скачок на `~2^64`/`inf`, тогда
   как 2-битный тернар ограничивает искажение величиной порядка единицы
   (`|Δw| <= 2`). Это разница в десятки порядков по амплитуде ошибки.

2. **Бинаризация спайком обрезает подпороговые возмущения.** Пороговая функция
   Хевисайда поглощает малые отклонения мембраны: если возмущение не перешло
   порог, на выход нейрона оно не влияет вообще. У float-суммы `y = W·x` такого
   фильтра нет — любое искажение слагаемого попадает в результат.

3. **Утечка мембраны даёт самовосстановление транзиентов.** LIF-динамика
   (`V(t+1) = leak * V(t) + ...`) экспоненциально гасит однократный сбой за
   несколько тиков, тогда как статический регистр МК держит сбитый бит до
   перезаписи.

4. **Распределённость локализует эффект.** Результат размазан по тысячам
   синапсов/нейронов, один сбитый синапс — лишь малое локальное возмущение;
   на МК сбитая float-ячейка или аккумулятор — единственная точка отказа.

5. **Отсутствие единого PC убирает целый класс фатальных управляющих отказов.**
   На МК битфлип в PC/SP роняет всю программу (зависание/reset/исполнение мусора);
   у нейроморфа нет PC/стека, поэтому такого отказа не существует в принципе.

**Мостик вперёд.** Все пять тезисов носят характер архитектурных ожиданий и
проверяются количественно в эксперименте: инжекция SEU в обе модели, измерение
доли фатальных и тихих ошибок, сравнение деградации точности — см.
`docs/03_experiment.md`.
